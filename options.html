Azure Key Vault Secret Revealer

Settings

Enter the Microsoft Entra app registration this extension signs in with. Both values are required. Your organization's admin can give you the IDs, or you can create the app registration yourself.

Add this under Authentication on your app registration. It changes with the extension ID, so a Chrome Web Store install and an unpacked install need different ones.

From the app registration's Overview page. Use an app registration with no client secret, and grant it the delegated Azure Key Vault permission.

Enter organizations to accept any work or school account (the app registration must be multi-tenant). Enter a tenant ID to sign in against one tenant only.

Changing either value signs you out. Sign in again from the extension popup.
